# Card 3 - Shahi Palna (Royal Baby Shower & Godh Bharai)

A fully 3D animated, interactive digital web invitation for Baby Showers, Godh Bharai, and Seemantham celebrations.

---

## 🌟 Highlights & 3D Interactive Features

- **3D Palace Gates Reveal:** Realistic 3D carved royal doors swing open in 3D perspective (`rotateY(-100deg)` and `rotateY(100deg)`), accompanied by sliding ribbon wrappers and unfolding star flaps.
- **3D Swinging Golden Cradle (Palna):** An ornate golden cradle swaying with natural pendulum physics in 3D space, decorated with jasmine and marigold garlands.
- **Floating Petal Physics:** Soft flower petals drifting across the palace courtyard.
- **Traditional Auspicious Blessings:** Customizable invocations (Ganesha, Bal Gopal/Krishna, Swaminarayan, Jain, Sikh, Christian).
- **Unrolling Family Scrolls:** Interactive parchment scrolls unrolling on scroll for Mother-to-be and Father-to-be families.
- **Live Event Countdown:** Real-time ticking countdown to the celebration day.
- **Ceremony Schedule Cards:** 4 dedicated baby shower ceremonies with time and venues.
- **Interactive GPS Navigation:** One-tap button opening Google Maps directions.
- **3D Polaroid Gallery:** Hanging picture frames with 3D tilt effect on hover/touch.
- **Instant WhatsApp RSVP:** Seamless guest confirmation with pre-filled baby blessing messages.
- **Dual View Modes:** Embedded iPhone desktop frame (with Dynamic Island) + Fullscreen responsive mobile layout.

---

## 🚀 How to Run & View

1. **Through the Cards Manager Portal:**
   - Open [http://localhost:8080/](http://localhost:8080/)
2. **Direct Standalone (In Browser):**
   - Double-click `card 3/standalone.html` in Windows Explorer or open `http://localhost:8080/card%203/index.html`.
